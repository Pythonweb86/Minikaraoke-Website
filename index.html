How to install

A simple guide for Android devices.

  1. Tap the Download APK button.
  2. Wait for the APK file to finish downloading.
  3. Open the downloaded APK from your browser or file manager.
  4. If Android asks, allow your browser or file manager to install unknown apps.
  5. Return to the installer and follow Android's prompts.

Only install APK files from sources you trust. Android may show security warnings for apps installed outside Google Play.
