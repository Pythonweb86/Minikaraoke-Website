How to install

A simple guide for Android devices.

  1. Tap the Download Latest APK button.
  2. On GitHub, open the latest release and locate the APK under Assets.
  3. Download the APK to your device.
  4. Open the downloaded file. If Android asks, allow your file manager or browser to install unknown apps.
  5. Return to the installer and follow Android's prompts.

Only install APK files from sources you trust. Android may show security warnings for apps installed outside Google Play.
