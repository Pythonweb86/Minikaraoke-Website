How to install

  1. Tap Download Latest APK.
  2. On GitHub, open the latest release and choose its APK file under Assets.
  3. When the download finishes, open the APK from your Downloads folder.
  4. If Android asks, allow your browser or file manager to install unknown apps, then return and install.

Only install APK files you trust. Android may display a security warning for apps installed outside Google Play.
