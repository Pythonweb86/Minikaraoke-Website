## 📥 Download behavior

The **Download APK** button looks up the latest public GitHub Release and links directly to its `.apk` asset. If the GitHub API is temporarily unavailable, it falls back to the known v1.14.4 APK asset.

## 🚀 Publishing

Upload the website files to the root of this repository and keep GitHub Pages configured for the `main` branch and `/(root)` folder.
